# 🚗 Used Car Sales Analysis using SQL

## 📌 Project Overview

This project analyzes used car sales data using SQL. It provides insights into car prices, brands, fuel types, transmission, sales, sellers, cities, and revenue.

## 🛠️ Technologies Used

* MySQL
* SQL
* GitHub

## 📊 Key Analysis

* Total number of cars
* Average car price
* Highest and lowest priced cars
* Brand-wise car analysis
* Fuel type analysis
* Manual vs Automatic comparison
* Total sales revenue
* Average selling price
* City-wise sales
* Seller-wise revenue
* Monthly revenue
* Year-wise sales
* Listed price vs sold price
* Top 5 expensive cars
* Car price ranking

## 🔍 SQL Concepts Used

* SELECT
* WHERE
* ORDER BY
* GROUP BY
* JOIN
* Aggregate Functions
* Subqueries
* RANK()
* Views
* Date Functions

## 🎯 Objective

The main objective of this project is to analyze used car sales data and extract useful business insights using SQL queries.

## 📈 Sample Insights

The analysis helps identify:

* Which car brands have higher average prices
* Which fuel type is most common
* Which cities generate higher sales revenue
* Which sellers have higher sales
* How car prices differ between listed and sold prices
* Which cars are the most expensive
